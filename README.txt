EDUGEST BENIN — PROTOTYPE V1

Contenu :
- index.html : page d'accueil et formulaires de démonstration
- css/styles.css : mise en page responsive
- js/app.js : interactions de démonstration

IMPORTANT :
Ceci est une maquette front-end uniquement. Elle ne contient pas de véritable authentification,

Ne saisissez pas de vrais mots de passe ou de données personnelles.
La prochaine étape sera de connecter le projet à Supabase et de déployer les fichiers sur Cloudflare Pages.

Pour tester localement : ouvrez index.html dans un navigateur.
